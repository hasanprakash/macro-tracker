# Release Notes - Version 1.0.2 (Build 6)

## Improvements & Bug Fixes

- **Weight Chart Scaling**: Fixed an issue where small weight changes appeared as a flat line; charts now dynamically scale with milestone badges.
- **Weight Precision**: Preserved exact decimal weight values across all charts and summary cards without rounding.
- **Calorie Bar Highlighting**: Fixed an issue on Android where selecting and unselecting days caused progress bar colors to disappear.
- **First-Launch Experience**: Tutorial tips now complete smoothly before showing active calorie alerts.
- **Faster AI Meal Scans**: Upgraded default food recognition to Gemini Flash Lite for faster analysis.
